# 📱 PHONEX Project

PHONEX is a sleek and modern phone store web application built with **React.js** and **SCSS**. It provides a full e-commerce experience including admin controls, dynamic product listings, and shopping cart functionality.

---

## ✨ Features

- 🛒 Add to Cart functionality  
- 🧑‍💼 Admin Dashboard layout  
- 🎨 Responsive UI with SCSS styling  
- 📦 Product display and categorization  
- ⚙️ Modular component structure

---

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/deval1804/PHONEX-Project.git

# Install dependencies
npm install

# Start the development server
npm start
